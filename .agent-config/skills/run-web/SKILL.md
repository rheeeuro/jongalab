# Next.js 실행 및 확인

1. `curl -s -o /dev/null -w "%{http_code}" http://127.0.0.1:3000/market`로 기존 서버를 확인한다.
2. 정상 서버가 없으면 `cd jongalab/frontend && npm run dev`를 지속 실행 세션으로 시작한다.
3. 백엔드 데이터가 필요하면 먼저 API 실행 스킬로 `:8000`을 확인한다.
4. 컴파일 완료 후 영향받은 라우트를 호출해 200 응답을 확인한다. 주요 라우트는 `/market`, `/stocks`, `/reports`, `/sectors`, `/feed`다.
5. 약 375px 폭을 우선으로 가로 스크롤, 터치 타깃, 가독성, 긴 콘텐츠를 시각적으로 점검한다.
6. 새로 시작한 프로세스와 검증 결과를 보고한다. 기존 프로세스는 임의로 종료하지 않는다.
